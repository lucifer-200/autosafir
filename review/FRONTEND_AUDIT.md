# گزارش بررسی و اصلاح فرانت AutoSafir

تاریخ: 2026-09-16. مبنا: کد پروژه، AGENTS.md و مشخصات محصول داخل مخزن، دو تصویر ارائه‌شده و تصاویر تازهٔ مرورگر. ساختار فعلی و هویت صفحهٔ اصلی حفظ شد؛ بازطراحی کامل یا انتشار انجام نشد.

## مسیرهای بررسی‌شده

1. **خانه — اصلاح‌شده:** کارت‌های تماس و انتخاب روز داخل قاب؛ تصاویر انتخاب‌های امروز هم‌اندازه؛ فضای خالیِ رزروشده برای 3D حذف؛ فاصلهٔ دکمه از کارت پایین کنترل شد. در موبایل ارتفاع هر دو کارت پایین حداقل 180 است و شمارنده حداقل 8 پیکسل از فلش فاصله دارد.
2. **موجودی و جزئیات خودرو — اصلاح‌شده:** پیش‌بارگذاری ناموفق مسیر جزئیات در خروجی استاتیک رفع؛ بیرون‌زدگی 32 پیکسلی بخش خودروهای مرتبط رفع؛ اندازهٔ عنوان متناسب با ستون و شکست امن نام‌های بلند.
3. **مقایسه — تست رفتاری سالم:** انتخاب حداکثر سه خودرو، حذف، ماندگاری انتخاب و تفاوت مشخصات بررسی شد.
4. **فروش خودرو و رزرو بازدید — تست رفتاری سالم:** مراحل فرم، خطاهای اعتبارسنجی، پیش‌انتخاب خودرو، تاریخ گذشته و تأیید صادقانهٔ دمو بررسی شد.
5. **درباره ما، شعب، تماس و ژورنال — خوانایی اصلاح‌شده:** صفحات و لینک‌های اصلی، شماره‌های تماس، بازخورد کپی نشانی و مقالات استاتیک بررسی شد؛ رنگ‌های روشن به عاجی گرم برگشت و متن طلایی تیره‌تر شد.
6. **ورود و نمای کلی مدیریت — اصلاح‌شده:** درخواست‌های 404 پیش‌بارگذاری حذف؛ ورود و خروج با مسیر استاتیک انجام می‌شوند؛ منوی بستهٔ موبایل دیگر قابل فوکوس نیست، منوی باز Tab را محدود می‌کند و Escape فوکوس را برمی‌گرداند.
7. **فهرست و فرم مدیریت — اصلاح‌شده:** بیرون‌زدگی 101 پیکسلی نوار فیلتر در عرض 1024 رفع؛ عنوان ستون‌ها با ردیف‌های RTL هم‌راستا؛ فیلدهای دارای راهنما ارتفاع و جای کنترل کناری را تغییر نمی‌دهند؛ خطا به کنترل مربوط متصل و مرز آن مشخص می‌شود؛ نوار ذخیره روی موبایل دیگر شناور نیست.
8. **داده و تنظیمات مدیریت — تست رفتاری سالم:** ایجاد، ویرایش، وضعیت SOLD، حذف با تأیید، انعکاس در سایت عمومی، export، رد import نامعتبر بدون تخریب داده، reset با تأیید و حالت شکستِ اتصال mocked بررسی شد.

## فایل‌های تغییرکرده

- `src/styles/home-motion.css` و `src/styles/home-bugfix.css`: هندسهٔ خانه و کارت‌ها.
- `src/styles/tokens.css`: رنگ‌های عاجی و توکن متن طلایی خوانا.
- `src/app/globals.css`: جزئیات خودرو، پنل واکنش‌گرا، هم‌ترازی فرم/ستون‌ها و حالت خطا.
- `src/components/home/home-experience.tsx`: حذف جای خالی و پیام موقت 3D.
- `src/components/vehicle/vehicle-card.tsx`: prefetch استاتیک.
- `src/components/ui/static-link.tsx` و تست آن: رفتار مشترک لینک‌های داخلی؛ import آن در branding، layout، home/showroom، compare، vehicle/detail، journal/card و صفحات about، branches، contact و journal جایگزین شد. مقصد و رفتار کلی ناوبری حفظ می‌شود.
- `src/components/admin/admin-shell.tsx`: نشست دمو و ناوبری قابل استفاده با صفحه‌کلید.
- `src/components/admin/admin-login.tsx`: انتقال بعد از ورود.
- `src/hooks/use-client-ready.ts` و تست آن: جلوگیری از ارسال پیش از hydration؛ `src/components/forms/booking-form.tsx`: ارسال فقط پس از آمادگی فرم و موجودی.
- `src/components/admin/admin-dashboard.tsx` و `admin-vehicle-list.tsx`: لینک‌های استاتیک.
- `src/components/admin/admin-vehicle-form.tsx`: انتقال پس از ذخیره و ارتباط خطا/راهنما با کنترل.
- `tests/e2e/home.spec.ts`، `foundation.spec.ts`، `admin.spec.ts` و `responsive.spec.ts`: اصلاح assertion قدیمی و افزودن رگرسیون هندسی، شبکه و دسترس‌پذیری.
- `playwright.config.ts`: زمان انتظار متناسب با محیط ویندوزِ زیر بار، بدون افزایش retry یا حذف assertion.
- `tools/capture-ui-audit.mjs` و `capture-ui-proof.mjs`: ابزار قابل تکرار ثبت تصویر، خطا و اندازه.
- همین گزارش و پوشه‌های تصاویر داخل `review/`.

## تست‌ها

| بررسی                                            | نتیجهٔ نهایی                   |
| ------------------------------------------------ | ------------------------------ |
| `npm run build`                                  | پاس؛ 24 صفحهٔ استاتیک          |
| `npm run typecheck`                              | پاس                            |
| `npm run lint`                                   | پاس؛ بدون warning              |
| `npm test -- --maxWorkers=2`                     | 28 فایل، 71 تست پاس            |
| `npx playwright test --workers=1`                | 70 پاس، صفر شکست، 30 skip عمدی |
| `npm run verify:static`                          | پاس                            |
| `git diff --check` و Prettier فایل‌های اصلاح‌شده | پاس                            |

موارد skip مربوط به آزمون‌های مختص موبایل/دسکتاپ و جلوگیری از تکرار ماتریسِ عرض در هر دو پروفایل هستند؛ تستِ باگ شناخته‌شده‌ای حذف یا skip نشد.

ماتریس E2E نهایی: عرض‌های 360، 390، 430، 768، 1024، 1280، 1440 و 1920 به‌علاوهٔ حالت افقی 844×390، در هر دو تم و reduced-motion. در هر ترکیب، 9 مسیر حیاتیِ عمومی و مدیریت بررسی می‌شوند؛ اسکرول افقی، نام‌های بلند، هم‌ترازی فیلدها، ستون‌ها، فاصلهٔ CTA هیرو و خطاهای شبکه/JavaScript assertion دارند.

126 تصویرِ ماتریسِ مرحلهٔ قبل در `responsive-final` ثبت شد: حداکثر بیرون‌زدگی افقی صفر، پاسخ شبکهٔ ناموفق صفر و خطای JavaScript صفر. 18 تصویر خانه نیز در `home-final` ثبت شده‌اند. پنج تصویرِ منتخب در `frontend-proof` ذخیره، باز و بررسی شدند؛ تصویر پنجم پس از آخرین تنظیمِ فاصلهٔ کارت موبایل گرفته شد. تصاویر فازهای قبل و گزارش JSON اندازه‌ها/شبکه برای مقایسه باقی مانده‌اند.

## محدودیت‌ها

آخرین تغییر فقط فاصله و ارتفاع کارت‌های موبایل بود؛ پس از اجرای سراسری E2E، مجموعهٔ مرتبطِ خانه و ماتریس واکنش‌گرایی دوباره اجرا شد.

- تست مرورگر روی Chrome/Chromium و شبیه‌سازی اندازهٔ موبایل انجام شد، نه Safari/iOS یا دستگاه فیزیکی؛ بازشدن صفحه‌کلید نرم‌افزاری جداگانه تأیید نشده است.
- تصاویرِ ماتریس برای کنترل خودکار اندازه/خطا ثبت شدند؛ نمونه‌های مهم به‌صورت بصری بازبینی شدند، نه تمام ترکیب‌ها با همان عمق.
- اسکرین‌شات full-page بدون پیمایش، ممکن است محتوای وابسته به ScrollTrigger را پیش از reveal نشان دهد؛ این به‌تنهایی شاهد خالی‌بودن صفحه نیست. تصاویر انتخاب نهایی در حالت reduced-motion ثبت شدند.
- جایگزین عکس اختصاصی در خودروهای بدون عکس همچنان به‌عنوان تصویر عمومیِ غیرنماینده مشخص است.
- این دمو backend یا احراز هویت امن ندارد؛ دادهٔ محلی در مرورگر باقی می‌ماند. هیچ اتصال خارجی، قیمت عمومی، کلید API یا انتشار اضافه نشد.
- نبود خطا در تست‌های فعلی به معنی تضمین نبودن تمام باگ‌های ممکن یا تأیید کامل WCAG نیست.
- اجرای فشار اولیه با `serve` پس از درخواست‌های بسیار با EMFILE متوقف شد؛ خطای زیرساخت تست بود. اجرای مجدد روی سرور استاتیک تازه انجام شد.
